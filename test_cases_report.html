1. Testing Methodology Overview

The test suite is partitioned into two complementary testing paradigms ensuring both logical accuracy and interface integrity:

  • Whitebox Testing (17 Cases): Focuses on internal code structures, scoring engine calculations, boundary conditions, input validator schemas, and isolated RBAC middleware units.
  • Blackbox Testing (17 Cases): Focuses on end-to-end REST API endpoint behaviors, HTTP status codes, authorization header verification, student answer-leak protection, and submission workflows.
